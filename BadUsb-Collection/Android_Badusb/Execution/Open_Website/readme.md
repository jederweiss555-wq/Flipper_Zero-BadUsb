# Open Website (Android)

Opens a URL in Chrome (or other browser) on an Android device.

- **Requirements:**
  - Replace `WEBSITE_URL` with the target URL
  - Device must be unlocked
  - Flipper Zero USB HID must be recognized (enable USB Debugging if using ADB mode)
- **Note:** Timing may need adjustment depending on device speed. The `GUI` key opens the home screen or app drawer on most Android launchers.
