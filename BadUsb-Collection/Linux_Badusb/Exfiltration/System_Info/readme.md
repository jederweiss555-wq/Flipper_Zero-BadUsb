# Linux System Info Exfiltration

Collects Linux system information (kernel, user, ID, IPs, OS, CPU, memory) and sends it to Discord.

- **Output:** Posted to Discord channel
- **Requirements:** `curl` (installed on most Linux distros), Discord webhook URL (replace `DISCORD_WEBHOOK_URL`)
- **CTRL+ALT+T** opens terminal on most GNOME/KDE desktops. Adjust for other DEs.
